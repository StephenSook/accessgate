## Session evidence, and what is deliberately withheld

`bob-usage-evidence.json` is generated by `scripts/export_bob_evidence.py`, which
reads the IBM Bob IDE's local session store (`~/.bob/db/bob.db`) read-only and
writes counts and totals:

| Measure | Value |
|---|---|
| Bob tasks in this workspace | 11, of which 5 match AccessGate |
| Messages | 645 (180 assistant, 441 tool results, 24 user) |
| Input tokens | 30,620,038 |
| Output tokens | 186,225 |
| Tracked spend | $77.02 |

441 tool-result messages is the number that actually answers "was Bob primary?",
because those are Bob reading and writing files in this repo, not conversation.

**Message bodies are excluded on purpose.** The transcripts contain the author's
verbatim planning prompts, which are strategy notes rather than engineering
artifacts, and a public repo is the wrong home for them. The aggregate proves
scale and shape without publishing the conversation. Regenerate it yourself from
a machine with the Bob IDE installed; the script is committed.

An earlier version of this file claimed no export was possible because Bob kept
history server-side. That was wrong. The store is local, in `~/.bob/db/bob.db`,
and the earlier check missed it.

## Scope note on the self-referential MCP loop

`.bob/mcp.json` registers AccessGate's own MCP server with Bob and pre-authorises
all three tools (`check_conformance`, `detect_gaps`, `score_captions`), and the
server itself is at `src/mcp_server/server.py`. Both halves are in this repo.
What is **not** in this repo is a transcript of Bob invoking those tools, for the
reason above. The honest reading is a wired capability, not a logged event.
